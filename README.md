# Rifas

Aplicación web para gestionar **solo los números** de una rifa (no hay pagos en línea).

- **Página pública**: el cliente ve los números libres, elige uno o varios y es redirigido a WhatsApp con un mensaje prellenado para coordinar el pago.
- **Panel admin**: el organizador crea rifas, ve el estado de cada número y lo marca como *apartado*, *pagado* o *debe*.
